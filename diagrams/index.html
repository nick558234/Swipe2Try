    How to View Diagrams¶

    All diagrams are created using Mermaid syntax and can be viewed:

    1. In this documentation - Rendered automatically by MkDocs
    2. In VS Code - Using the Mermaid preview extension
    3. On GitHub - Native Mermaid rendering support
    4. Mermaid Live Editor - Copy the content to mermaid.live for editing

    Diagram Types Used¶

    • Flowcharts - For process flows and decision trees
    • Class Diagrams - For entity relationships and object structure
    • Architecture Diagrams - For system component relationships
    • Sequence Diagrams - For interaction flows (when applicable)

    Each diagram includes comments and clear labeling to ensure accessibility and understanding.
